
# AWS Containerized Web Application

## Overview

This project aims to build a containerized web application infrastructure on AWS using Amazon ECS Fargate and AWS CloudFormation.

The infrastructure is defined using CloudFormation templates written in YAML.

## Architecture

- Amazon VPC
- Application Load Balancer
- Amazon ECS (Fargate)
- Amazon ECR
- Amazon RDS (PostgreSQL)
- AWS Secrets Manager
- Amazon CloudWatch

## Infrastructure as Code

AWS CloudFormation

## CI/CD

GitHub Actions with OpenID Connect (OIDC)

## Project Objectives

- Learn AWS CloudFormation
- Understand Docker and container technologies
- Build an ECS Fargate environment
- Implement CI/CD automation
- Practice AWS monitoring and operations
